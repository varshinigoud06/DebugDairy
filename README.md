DebugDairy — Learning Analytics Application

DebugDairy is a web-based learning analytics application that helps learners record, analyze, and learn from their mistakes.

Features

- Record coding questions and attempted solutions.
- Categorize mistakes and identify their causes.
- Review corrected concepts and previous mistakes.
- Track learning progress and recurring errors.

Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Visualization: Chart.js

Project Structure

- "frontend/" — User interface and web pages
- "backend/" — Java backend and REST APIs
- "database/" — Database documentation
- "docs/" — Project documentation
- "debugdairy.sql" — SQL database script

Objective

To help learners understand their weaknesses, avoid repeating mistakes, and improve their problem-solving skills.

Setup

Refer to the README files inside the "backend/", "frontend/", and "database/" folders for component-specific setup instructions.
